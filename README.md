# Task 01 - Population Distribution Visualization

This project is part of my internship with **Prodigy InfoTech** under the **Data Science Track**.

## 🔍 Task Objective

Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable, such as the distribution of **population across countries**.

## 📊 Description

- The dataset was sourced from the **World Bank**: [World Bank Population Data](https://data.worldbank.org/indicator/SP.POP.TOTL)
- The notebook uses **Python**, with libraries such as:
  - `pandas`
  - `matplotlib`
  - `seaborn`
- A bar chart is created to show the population distribution across selected countries.

## 📁 Files Included

- `Task 1 Population Distribution Visualization.ipynb`: Jupyter Notebook containing data loading, cleaning, and visualization.

## 🧠 Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization (Bar Charts, Histograms)
- Use of external datasets (World Bank)

## 📎 Sample Output

- Population bar chart sorted by country
- Histogram of population distribution

## ✅ Outcome

Successfully visualized global population distribution, identifying patterns among countries with the highest and lowest population.
